# Sound assets (ElevenLabs)

Put two files here. Until they exist, the app uses built-in fallback sounds.

| File | Make it in ElevenLabs | Prompt / text |
|---|---|---|
| `thunder.mp3` | **Sound Effects** | "close, loud rolling thunder crack, dramatic storm" (~4 s) |
| `storm_voice.mp3` | **Text to Speech** | "Warning. A market storm is coming. Hold on to your assets." |

Download each one, rename it exactly as above, and drop it in this folder.
